# LaraRose API 🌹

نظام خلفي (Backend API) متكامل مبني بإطار عمل **Laravel** لخدمة تطبيق موبايل لمتجر إلكتروني. يوفر النظام واجهات برمجة تطبيقات (RESTful APIs) سريعة، آمنة، وجاهزة للربط الفوري.

## 🚀 التقنيات المستخدمة
- **إطار العمل:** Laravel
- **قاعدة البيانات:** MySQL
- **المصادقة والحماية:** Laravel Sanctum (Token-based Auth)

## ✨ الميزات الأساسية
- **نظام المصادقة:** تسجيل دخول وإنشاء حسابات للزبائن والمدراء باحترافية.
- **إدارة الحساب الشخصي (Profile):** إمكانية تعديل الزبون لبياناته وكلمة المرور الخاصة به.
- **عناوين التوصيل (Addresses):** نظام لإضافة وحذف عناوين الزبون مع دعم إحداثيات الخريطة (Latitude & Longitude).
- **إدارة المنتجات (CRUD):** إضافة المنتجات، رفع الصور وتخزينها، وتوليد روابط الصور تلقائياً.
- **سلة المشتريات (Cart):** نظام متكامل لإضافة المنتجات، تعديل الكميات، وحذفها من السلة مؤقتاً.
- **نظام الطلبات (Orders):** تحويل السلة إلى طلبات شراء نهائية ومتابعة حالتها من قبل الإدارة.
- **البحث والفلترة:** محرك بحث متقدم باسم المنتج، وتصفية النتائج حسب القسم.
- **المفضلة (Favorites):** إمكانية إضافة وإزالة المنتجات من قائمة المفضلة الخاصة بكل مستخدم.
- **التواصل (Contact Us):** استقبال وحفظ رسائل الزوار واستفساراتهم.
- **الإعدادات والصفحات الثابتة:** نقطة نهاية (Endpoint) شاملة لتزويد التطبيق بإحداثيات المتجر، الأسئلة الشائعة (FAQ)، سياسة الخصوصية، والشروط والأحكام.
