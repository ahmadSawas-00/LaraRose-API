# LaraRose API 🌹

نظام خلفي (Backend API) متكامل مبني بإطار عمل **Laravel** لخدمة تطبيق موبايل لمتجر إلكتروني. يوفر النظام واجهات برمجة تطبيقات (RESTful APIs) سريعة، آمنة، وجاهزة للربط الفوري.

## 🚀 التقنيات المستخدمة
* **إطار العمل:** Laravel
* **قاعدة البيانات:** MySQL
* **المصادقة والحماية:** Laravel Sanctum (Token-based Auth)

## ✨ الميزات الأساسية
* **نظام المصادقة:** تسجيل دخول وإنشاء حسابات للزبائن والمدراء باحترافية.
* **إدارة المنتجات (CRUD):** إضافة المنتجات، رفع الصور وتخزينها (Storage)، وتوليد روابط الصور تلقائياً (Accessors).
* **سلة المشتريات (Cart):** نظام متكامل لإضافة المنتجات، تعديل الكميات، وحذفها من السلة مؤقتاً.
* **نظام الطلبات (Orders):** تحويل السلة إلى طلبات شراء نهائية ومتابعة حالتها.
* **البحث والفلترة (Query Params):** محرك بحث متقدم باسم المنتج، وتصفية النتائج حسب القسم أو نطاق السعر.
* **المفضلة:** إمكانية إضافة وإزالة المنتجات من قائمة المفضلة الخاصة بكل مستخدم.
